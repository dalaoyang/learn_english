## 核心考点一：阅读判断要看原文证据

| 判断 | 标准 |
| --- | --- |
| True | 原文支持题干，包括同义改写或能够确定推出的信息。 |
| False | 原文信息与题干矛盾。 |
| Not Given | 原文信息不足以判断题干，既不能证实也不能否定。 |

“原文没有相同的词句”不等于Not Given；“我觉得不对”也不能代替False需要的矛盾证据。

用今天的原文 **Chen studies English four days a week.** 来看：

- “每周学超过三天”：True，四天必然超过三天。
- “每天都学”：False，每周四天与每天矛盾。
- “经理要求他学”：Not Given，没有交代经理是否提出要求。

## 核心考点三：句子主干与like后的动作形式

今天的新活动句可规范写成：

> **I like playing basketball on Sunday.**

| 部分 | 在这句话中的作用 |
| --- | --- |
| I | 主语：谁？ |
| like | 主要动词：喜欢。 |
| playing basketball | 喜欢的活动，整体作宾语。 |
| on Sunday | 时间状语：什么时候？ |

like允许以下搭配：

- **like + 名词**：I like basketball.
- **like + doing**：I like playing basketball.
- **like + to + 动词原形**：I like to play basketball.

本句不能写like play。规则针对like的搭配，不推广成“所有第二个动词都加-ing”。
