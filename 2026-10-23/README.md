# 2026-10-23 · 表达身体不适与预约求助

[前一天](../2026-10-22/README.md) · [学习日历](../README.md) · [下一天](../2026-10-24/README.md)

**今天的目标：** 用简单英语说明一项身体不适，表达需要帮助，并询问能否预约。

**建议时间：** 30 分钟。按“复习 5 分钟 → 词汇 5 分钟 → 朗读 8 分钟 → 练习 9 分钟 → 记录 3 分钟”完成。

## 1. 先复习

复习昨天的 tomorrow 和 be going to；今天保留未来时间表达，并加入更礼貌的预约问法 Could I ...。

## 2. 核心词句

| 英语 | 中文 |
| --- | --- |
| headache | 头痛 |
| sore throat | 喉咙痛 |
| feel sick | 感到不舒服；恶心 |
| need help | 需要帮助 |
| appointment | 预约 |
| pharmacy | 药店 |
| rest | 休息 |
| water | 水 |

## 3. 实用句子

1. **I have a headache.**  
   我头痛。
2. **I have a sore throat.**  
   我喉咙痛。
3. **I don't feel well and need some help.**  
   我感觉不舒服，需要一些帮助。
4. **Could I make an appointment for tomorrow?**  
   我可以预约明天吗？

## 4. 对话朗读

**来访者:** I don't feel well.  
**接待员:** Would you like to make an appointment?  
**来访者:** Yes, could I make one for tomorrow?  
**接待员:** Yes. Can you come at ten?  

先朗读两遍，再替换成自己的信息；如果方便，可以录下第二遍并回听。

## 5. 表达练习

1. 进行一次预约对话：先说明一个症状，再说需要帮助，最后询问能否预约明天。交换角色后再练一次；重点练习 have a headache 和 have a sore throat。

把自己的答案写在 [学习记录](notes.md) 中。先尝试独立表达，再查词或请学习助手纠正。
