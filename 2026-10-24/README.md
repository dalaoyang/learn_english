**今天的目标：** 说明已有预订，办理入住，并询问早餐和退房时间。

**建议时间：** 30 分钟。按“复习 5 分钟 → 词汇 5 分钟 → 朗读 8 分钟 → 练习 9 分钟 → 记录 3 分钟”完成。

## 1. 先复习

复习昨天的 appointment 和今天的 reservation：前者常指与人或机构约定时间，后者常指预订房间或座位；继续练习礼貌请求。

## 2. 核心词句

| 英语 | 中文 |
| --- | --- |
| reservation | 预订 |
| check in | 办理入住 |
| check out | 办理退房 |
| room | 房间 |
| key | 钥匙；房卡 |
| night | 夜晚；住宿的一晚 |
| breakfast | 早餐 |
| included | 包含在内的 |

## 3. 实用句子

1. **I have a reservation under the name Li.**  
   我有预订，预订姓名是 Li。
2. **I'd like to check in, please.**  
   我想办理入住。
3. **Is breakfast included?**  
   包含早餐吗？
4. **What time do I need to check out?**  
   我需要几点退房？

## 4. 对话朗读

**客人:** I'd like to check in, please.  
**前台:** Do you have a reservation?  
**客人:** Yes, under the name Li.  
**前台:** Great. Breakfast is included.  
**客人:** What time is check-out?  
**前台:** Eleven a.m.  

先朗读两遍，再替换成自己的信息；如果方便，可以录下第二遍并回听。
