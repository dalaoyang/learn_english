## 每天怎么做

- **每天30分钟**：旧题复习5分钟 → 一个主任务20分钟 → 反馈订正5分钟。复习选1–2道真实错题或猜对题；没有旧题时用这段时间核对当前题的依据。
- **有时间再做**：在30分钟总预算内替换部分任务做针对性加练，忙时可用10分钟精简版。今天先保留10分钟基线，提交后再用剩余时间解析与补练。
- **根据实际表现加难**：同时看答案、依据、把握标记和用时；表现稳定时，每次只增加篇幅、同义改写或干扰项难度中的一个维度。猜对和依据不清仍要复习，卡住时缩小范围。
- 每题标记“有依据／不确定／猜”。先作答，再给答案与解析；猜对题也复习。
- 阅读核对原文证据、同义改写和干扰项；特别区分原文矛盾与原文未提及。语法只讲当前题的一两个规则。
- 作文从简单句与改写起步，再依据实际完成情况逐步练约100词短文。先写清意思，再修正错误。
- 没做完时，下次先接续当前的一小项，并减少新题；不堆积整套试卷、背词任务或完整语法课程。

## 怎样开始

打开对应日期的 `README.md`，在 `notes.md` 作答，或直接把答案发给学习助手。你可以说：`带我做今天的30分钟任务，根据前面的表现调整难度，先出题，等我回答后再解析。`

所有自编题标注“仿真练习”。引用历年真题时提供可核验来源，不虚构题目年份或官方答案。

这是Markdown学习仓库，直接阅读和填写即可；无需安装依赖或启动服务。记录只反映实际作答，不根据少量题目认定英语等级。

## 每天结束时

学习助手必须给出明确收尾建议：可以结束／需要短补练／需要下次再验证，并说明当天结果、仍需补的1–2个点、最小补练和预计用时、明日复习重点。

必要基础优先放进原有30分钟，减少新题。若确需额外补练，建议可选5–10分钟，明确目标和加练后的总用时；完成目标即结束，不把每天默认时长扩展到40分钟。实际错题与尚未展示的能力分开判断。

## 尽量贴近真题

根据真实作答逐步向考试要求靠拢：基础短题 → 更完整的篇章与选项 → 有可靠来源的真题段落或题组 → 限时输出。能说明依据并较稳定完成时再提高一个维度，仍卡住时先补当前基础。

优先使用可核验来源的13000历年题，并给出年份、课程代码与来源。当前题库尚无经核验的13000原卷，已出题属于自编仿真；来源未核实的资料不标为真题，旧课00015参考题不冒充13000。
