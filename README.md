## 学习节奏

- 每周固定四天：**周二、周四、周六、周日**。周二、周四各30–45分钟；周六、周日各60–90分钟，可分段完成。
- 临时有空只做当周错题、短变式或订正，不把额外时间变成必须任务，也不堆积未完成题组。
- 每次只讲当前最需要的一两个规则；每题记录答案、把握、原文依据和用时。猜对和依据不清的题继续复查。
- 先出题，收到作答后再给答案和解析。每题标记“有依据／不确定／猜”，猜对与依据不清的题也复习。
