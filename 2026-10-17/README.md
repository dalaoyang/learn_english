# 2026-10-17 · 买东西：价格、尺寸与支付

[前一天](../2026-10-16/README.md) · [学习日历](../README.md) · [下一天](../2026-10-18/README.md)

**今天的目标：** 能询问价格和尺寸，提出试穿或支付请求；能区分单件 it 与复数 these。

**建议时间：** 30 分钟。按“复习 5 分钟 → 词汇 5 分钟 → 朗读 8 分钟 → 练习 9 分钟 → 记录 3 分钟”完成。

## 1. 先复习

回忆昨天点餐的两个礼貌请求；把 Can I have ...? 换成今天的 Can I try ...? 和 Can I pay ...?。

## 2. 核心词句

| 英语 | 中文 |
| --- | --- |
| How much ...? | ……多少钱？ |
| size | 尺寸；尺码 |
| try on | 试穿 |
| small | 小号；小的 |
| large | 大号；大的 |
| pay by card | 刷卡支付 |
| I'll take it. | 我买这个。 |

## 3. 实用句子

1. **How much is this shirt?**  
   这件衬衫多少钱？
2. **Do you have this in a larger size?**  
   这件有更大的尺码吗？
3. **Can I try it on?**  
   我可以试穿吗？
4. **Can I pay by card?**  
   我可以刷卡吗？

## 4. 对话朗读

**Customer:** How much is this shirt?  
**Staff:** It's twenty dollars.  
**Customer:** Do you have it in a medium?  
**Staff:** Yes. Would you like to try it on?  
**Customer:** Yes, please. It fits well. I'll take it.  
**Staff:** Great. You can pay here.  

先朗读两遍，再替换成自己的信息；如果方便，可以录下第二遍并回听。

## 5. 表达练习

1. 选择一件身边的物品，设定一个价格，用英文问价并回答。
2. 用替换法练 3 组问价：this shirt / this bag / these shoes。复数用 How much are these shoes?
3. 完成一次四步购物对话：问价 → 问尺寸 → 试穿 → 支付。

把自己的答案写在 [学习记录](notes.md) 中。先尝试独立表达，再查词或请学习助手纠正。

## 6. 今日自测

1. 选择：How much is / are these shoes?
2. 把“我可以试穿吗？”译成英文。
3. I'll take it. 在购物时是什么意思？
