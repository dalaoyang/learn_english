# 手机答题站

这是一个无构建依赖的静态原型，代码和学习记录放在同一个仓库。直接打开 `index.html` 即可预览；仓库里的 Pages 工作流会把 `site/` 发布为站点。首次使用需要在 GitHub 仓库设置中启用 Pages，并选择 GitHub Actions。当前原型含一个已收尾日页面和长期计划入口，后续按日期增加题面。

## 添加一天

在 `data.js` 的 `days` 数组中增加一天，题目只放题面，不放答案或解析。题型支持：

- `choice`：`options` 数组显示单选按钮；
- `text`：显示文本输入框；
- 每题自动附加把握按钮和证据输入框。

答案和解析继续写在每日 Markdown 记录里。站点的 `localStorage` 只保存本机草稿，点击“复制本次答案”后粘贴到聊天中。它没有账号和跨设备同步功能。
