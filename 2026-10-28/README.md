# 2026-10-28 · 表达喜好与简单比较

[前一天](../2026-10-27/README.md) · [学习日历](../README.md) · [下一天](../2026-10-29/README.md)

**今天的目标：** 说出自己的偏好和原因，用 cheaper 或 more comfortable 比较两个物品。

**建议时间：** 30 分钟。按“复习 5 分钟 → 词汇 5 分钟 → 朗读 8 分钟 → 练习 9 分钟 → 记录 3 分钟”完成。

## 1. 先复习

复习昨天的 jacket 与 wear，再比较两件衣物。注意 cheaper 与 more comfortable 的形式不同，比较对象前常用 than。

## 2. 核心词句

| 英语 | 中文 |
| --- | --- |
| think | 认为 |
| like | 喜欢 |
| prefer | 更喜欢 |
| better | 更好的 |
| cheaper | 更便宜的 |
| more comfortable | 更舒适的 |
| than | 比 |
| because | 因为 |

## 3. 实用句子

1. **I think this café is nice.**  
   我觉得这家咖啡馆不错。
2. **This jacket is cheaper than that one.**  
   这件外套比那件更便宜。
3. **These shoes are more comfortable than those.**  
   这双鞋比那双更舒适。
4. **I prefer tea because I don't like coffee.**  
   我更喜欢茶，因为我不喜欢咖啡。

## 4. 对话朗读

**A:** Which jacket do you prefer?  
**B:** I prefer the blue one.  
**A:** Why?  
**B:** It's cheaper and more comfortable.  

先朗读两遍，再替换成自己的信息；如果方便，可以录下第二遍并回听。

## 5. 表达练习

1. 选择两件物品，进行一分钟比较：说更喜欢哪件、给出原因，再从价格或舒适程度中选一个方面比较。

把自己的答案写在 [学习记录](notes.md) 中。先尝试独立表达，再查词或请学习助手纠正。

## 6. 今日自测

1. 补全：This jacket is cheaper ___ that one.
2. comfortable 表达“更舒适”时，用 comfortabler 还是 more comfortable？
3. because 在句子中引出什么？

<summary>完成后展开参考答案</summary>

2. more comfortable
3. 原因。
