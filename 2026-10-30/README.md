# 2026-10-30 · 写一段日常小故事或短邮件

[前一天](../2026-10-29/README.md) · [学习日历](../README.md) · [下一天](../2026-10-31/README.md)

**今天的目标：** 写一段约四十至六十词的短消息，清楚区分过去发生的事、现在的情况和未来计划。

**建议时间：** 30 分钟。按“复习 5 分钟 → 词汇 5 分钟 → 朗读 8 分钟 → 练习 9 分钟 → 记录 3 分钟”完成。

## 1. 先复习

复习过去经历中的 studied 和 went、未来计划中的 be going to，以及昨天的澄清表达。今天把这些能力串成一段有时间顺序的短文。

## 2. 核心词句

| 英语 | 中文 |
| --- | --- |
| Hi | 嗨；非正式邮件开头 |
| yesterday | 昨天 |
| after that | 在那之后 |
| then | 然后 |
| finally | 最后 |
| today | 今天 |
| tomorrow | 明天 |
| Best | 非正式邮件结尾的祝好 |

## 3. 实用句子

1. **Yesterday, I studied English at home.**  
   昨天，我在家学英语。
2. **After that, I went for a walk.**  
   在那之后，我去散了步。
3. **Today, I'm writing a short message to a friend.**  
   今天，我正在给一位朋友写一条短消息。
4. **Tomorrow, I'm going to practice speaking.**  
   明天，我打算练习口语。

## 4. 对话朗读

**A:** How was your day?  
**B:** It was good. I studied English.  
**A:** What did you do after that?  
**B:** I went for a walk.  

先朗读两遍，再替换成自己的信息；如果方便，可以录下第二遍并回听。

## 5. 表达练习

1. 给假想朋友写一条四十至六十词的短消息：写昨天的两件事、今天的一件事和明天的一项计划。加入一个衔接词；写完朗读一次，圈出过去式与 be going to。

把自己的答案写在 [学习记录](notes.md) 中。先尝试独立表达，再查词或请学习助手纠正。

## 6. 今日自测

1. After that 表示原因还是先后顺序？
2. 描述昨天去散步，go 应变成哪个过去式？
3. 补全：Tomorrow, I'm going to ___ speaking.
