# 2026-10-27 · 天气与穿着

[前一天](../2026-10-26/README.md) · [学习日历](../README.md) · [下一天](../2026-10-28/README.md)

**今天的目标：** 描述当天的天气和自己的穿着，并给出带伞或穿外套的简单建议。

**建议时间：** 30 分钟。按“复习 5 分钟 → 词汇 5 分钟 → 朗读 8 分钟 → 练习 9 分钟 → 记录 3 分钟”完成。

## 1. 先复习

复习昨天的具体时间表达；今天换成描述当下的天气。比较表示天气的 It's 与表示自己正在穿着的 I'm wearing。

## 2. 核心词句

| 英语 | 中文 |
| --- | --- |
| sunny | 晴朗的 |
| rainy | 下雨的；多雨的 |
| cold | 寒冷的 |
| warm | 温暖的 |
| jacket | 夹克；外套 |
| umbrella | 雨伞 |
| wear | 穿；戴 |
| take | 带上；携带 |

## 3. 实用句子

1. **It's cold and rainy today.**  
   今天又冷又下雨。
2. **I'm wearing a jacket.**  
   我穿着一件外套。
3. **Please take an umbrella.**  
   请带上一把雨伞。
4. **Is it warm outside?**  
   外面暖和吗？

## 4. 对话朗读

**A:** What's the weather like today?  
**B:** It's cold and rainy.  
**A:** Should I take an umbrella?  
**B:** Yes, and wear a warm jacket.  

先朗读两遍，再替换成自己的信息；如果方便，可以录下第二遍并回听。

## 5. 表达练习

1. 做一分钟的天气播报：描述天气，说明穿着，再提出一个穿衣或携带物品的建议。最后问假想伙伴外面是否暖和。

把自己的答案写在 [学习记录](notes.md) 中。先尝试独立表达，再查词或请学习助手纠正。

## 6. 今日自测

1. 描述天气时，It's cold 中的 it 指一个人吗？
2. 补全：Please take ___ umbrella.
3. wear a jacket 和 take an umbrella 分别强调什么？

2. an
