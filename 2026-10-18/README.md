# 2026-10-18 · 填句补文

[学习日历](../README.md) · [备考背景](../STUDY_PROFILE.md) · [学习记录](notes.md)

**状态：计划；尚未出题。** 实际题目将在当天根据已提交的练习与错题记录生成。

**当天目标：** 观察能否用上下文的指代、逻辑和内容衔接判断句子位置，并说出依据。

## 主任务 · 20分钟

**计划；尚未出题。**

按前几天表现编写约80词的短文，设置2个句子空缺及3个候选句，其中1句多余。每空选句并标记“有依据／不确定／猜”，用中文写一句位置判断依据；不提前解释连接词或指代对应。题目统一标注“自编·仿真练习”，等回答后再指出空前、空后的证据及多余句不适合的原因。

## 旧题复习 · 5分钟

依据实际错题和猜对记录，挑1～2道短变式复习，优先涉及指代、转折或因果关系。没有可用错题时复核本人标记不确定的一题；无记录则写“暂无”。不预设学生已会某条规则，不积压漏做任务。

按“旧题复习5分钟 → 一个主任务20分钟 → 反馈订正5分钟”安排，合计30分钟。没有旧题时，用复习时段核对当前题依据；未完成的任务先接续，并减少新题。

## 反馈订正 · 5分钟

解析后选择一个空，重新说明填入句子如何同时连接前后文，再口头复述这段短文的大意。反馈订正5分钟，全天总量不超过30分钟。

## 作答和记录

每题标记“有依据／不确定／猜”。先将答案与证据或理由写进 [学习记录](notes.md)，提交后再解析和修正。

自编题标注“仿真练习”。采用历年真题时应给出可核验来源，不编造年份或官方答案。具体考试日期待确认，确认后再调整后续日期安排。

## 根据前面表现增强出题

以上篇幅、题量与写作字数作为起点。根据已经提交的答案、依据、把握程度和用时调整；能稳定独立答对并说明依据时，每次只增加一个难度维度。猜对与依据不清的题继续做短变式，卡住时先巩固。写作能独立写清简单句后，再逐步增强到连贯短段与约100词短文。

普通选做从当天30分钟内调配。每日结束按备考约定给出收尾判断；若确需额外基础补练，明确可选5–10分钟、解决的问题及总用时，完成即止。所有新题先给题目，收到作答后再给答案与解析。
