**今天的目标：** 能介绍工作或学习的基本情况，询问他人的安排，并请求帮助或说明不理解。

**建议时间：** 30 分钟。按“复习 5 分钟 → 词汇 5 分钟 → 朗读 8 分钟 → 练习 9 分钟 → 记录 3 分钟”完成。

## 1. 先复习

不看 10 月 13 日内容，先说一遍自己的作息；再回忆昨天问路时如何礼貌开场和致谢。

## 2. 核心词句

| 英语 | 中文 |
| --- | --- |
| work | 工作 |
| study | 学习 |
| start | 开始 |
| finish | 结束；完成 |
| need help | 需要帮助 |
| understand | 理解 |
| Could you ...? | 你能……吗？ |

## 3. 实用句子

1. **I work from nine to six.**  
   我从九点工作到六点。
2. **What do you study?**  
   你学习什么？
3. **I need help with this question.**  
   我需要有人帮我解答这个问题。
4. **Could you explain that again?**  
   你能再解释一遍吗？

## 4. 对话朗读

**A:** What time do you start work?  
**B:** I start at nine. How about you?  
**A:** I start at eight thirty.  
**B:** Do you study English after work?  
**A:** Yes. Could you help me with this question?  
**B:** Sure. Let's look at it together.  

先朗读两遍，再替换成自己的信息；如果方便，可以录下第二遍并回听。

## 5. 表达练习

1. 根据实际情况选择工作或学习，写开始时间、结束时间和一项常做的任务。
2. 写 3 个向别人提问的句子，至少用到 What time ...? 和 Do you ...?。
3. 把一个暂时不懂的问题写下来，练习 I don't understand ____. Could you explain it again?。

把自己的答案写在 [学习记录](notes.md) 中。先尝试独立表达，再查词或请学习助手纠正。
